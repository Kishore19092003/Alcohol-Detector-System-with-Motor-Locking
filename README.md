# Alcohol Detector System with Motor Locking

## 📌 Project Overview

The **Alcohol Detector System with Motor Locking** is a safety-oriented system designed to detect alcohol presence and automatically prevent motor operation when the detected alcohol level exceeds a predefined threshold.

The system uses an **Arduino Uno**, **MQ-3 alcohol sensor**, relay module, DC motor, and buzzer to detect alcohol and control the motor accordingly.

## 🎯 Objectives

* To develop an automatic alcohol detection system.
* To detect alcohol presence using an MQ-3 sensor.
* To automatically lock the motor when alcohol is detected above the threshold.
* To provide an audible warning using a buzzer.
* To improve safety through automatic motor control.

## 🔧 Components Used

* Arduino Uno
* MQ-3 Alcohol Sensor
* Relay Module
* DC Motor
* Buzzer
* Power Supply
* Connecting Wires

## ⚙️ Working Principle

The **MQ-3 alcohol sensor** detects the presence of alcohol and sends an analog signal to the Arduino Uno.

The Arduino continuously monitors the sensor reading and compares it with a predefined threshold value. When the alcohol level exceeds the threshold, the Arduino activates the relay to **lock or stop the motor** and turns ON the buzzer as a warning.

When the alcohol level is below the threshold, the relay allows the motor to operate normally.
